# Concept figures

Concept visualisations and sketches from the project development process, extracted from
[`/process/DECO3500_Project_Development_Notebook.pdf`](../../process/DECO3500_Project_Development_Notebook.pdf)
so they can be referenced from the wiki and from markdown in this repo.

These are concept visualisations produced during ideation, not engineering drawings.

| File | What it shows | Stage |
|---|---|---|
| `01-stories-to-design-opportunity.jpg` | Refined Stories 1 and 5 converging into the design opportunity | Research synthesis |
| `02-odyssey-escape.jpg` | Odyssey Escape — deadline pressure as a nautical escape, with multiplayer state | Concept 1 |
| `03-deadline-shark-nautical.jpg` | The same direction as a physical object — boat between danger and lighthouse | Concept 1 |
| `04-conquest-wheel.jpg` | 讨伐之轮 Conquest Wheel — rotating schedule, characters as planned periods | Concept 3 |
| `05-physical-landscape.jpg` | Time as a Physical Landscape — planned and actual timelines in modular blocks | Concept 4 (direction selected) |
| `06-time-tokens-and-tower.jpg` | Time Tokens & Time Tower — the reduced, buildable system | Final direction |
| `07-form-sketches.jpg` | Early form exploration — capsule, triangular body, cylinder | Form exploration |

| `09-parts-and-assembly.jpg` | Parts and assembly breakdown of the cylindrical version | First functional form |

## Referencing these from the wiki

The wiki is a separate repository, so it cannot use relative paths into this one. Use the
raw URL:

```markdown
![Odyssey Escape](https://raw.githubusercontent.com/CcYyYcC/DECO3500_Team3/main/design/concepts/02-odyssey-escape.jpg)
```

To control width, use HTML instead:

```html
<img src="https://raw.githubusercontent.com/CcYyYcC/DECO3500_Team3/main/design/concepts/02-odyssey-escape.jpg" width="700">
```
