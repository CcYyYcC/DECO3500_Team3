# Build photos

Photographs of the current build, for embedding in the wiki and in markdown across this repo.

Sourced from the final A2 poster
([`../Time_Tokens_A2_Poster_v121.pdf`](../Time_Tokens_A2_Poster_v121.pdf)) at print
resolution. Replace these with the original camera files when they are added to the repo —
the filenames can stay the same so nothing linking to them breaks.

| File | What it shows |
|---|---|
| `current-build-tower-and-tokens.jpg` | Latest build — three Tokens, the Tower's accumulated activity traces, and the hook-and-loop planning strips |
| `interaction-flip-track-transfer.jpg` | Flip prompt, timing, and transfer confirmation on the built Token |

Hardware iteration figures live in [`/prototype/figures/`](../../prototype/figures); concept
visualisations live in [`/design/concepts/`](../concepts/README.md).
