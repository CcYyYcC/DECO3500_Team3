## What was actually run

**Test A only.** One real participant per session, with a **programmed housemate (B_sim)**
occupying the second column of the Tower. One hour was simulated as eight seconds.

**Test B — two real users in a shared setting — is specified in the protocol but was not
conducted.** Real paired interaction therefore remains unverified, and nothing in this folder
should be read as evidence of genuine multi-user behaviour.

## Quoting this round

Three constraints, all from the analysis document:

1. **The transcripts are lightly cleaned, not verbatim.** Fillers and non-substantive pauses
   were removed and recognition errors corrected. Check the recordings above for
   publication-grade quotes.
2. **Much of the P02 material is unattributed.** In the staged housemate discussion several
   voices are not separated turn by turn. Only lines tagged `P01:` are attributed to a named
   participant. Report the rest as *unattributed staged-discussion remarks* — not as "P02 felt
   anxious."
3. **Segment IDs are locators, not timestamps.** `P02-044` identifies a position in the cleaned
   transcript.

> **Participant labels are not continuous across rounds.** Round 1's P01–P03 and this round's
> P01–P02 are **different people**. Always name the round alongside the segment ID.
