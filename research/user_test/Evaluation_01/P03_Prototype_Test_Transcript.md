# English translation

**Interviewer** We're starting the test now. Flipping this token 180 degrees starts the timer; one cycle represents one hour. When it ends, the tower responds. For example...

**Interviewer** This means it didn't start successfully. First, we'll do a think-aloud test. Imagine you're about to study for an hour. What would you do?

**Participant** I'd start using the token. It looks like an hourglass, so I suppose I'd turn it over. But it doesn't seem to respond.

**Interviewer** It hasn't started.

**Participant** Now there's a progress bar. When it's full, I can see something fall down.

**Interviewer** What do you think the token is showing?

**Participant** At first it was an hourglass. After I flipped it, there was a bar.

**Interviewer** Has it filled up? When it fills up, that's one hour. Can you understand that?

**Participant** I can roughly understand it, but I might not fully get it. I'd need a prompt.

**Interviewer** Now please record another hour of study.

**Participant** I'd probably turn it back and then over again. That didn't work. Then I saw the progress bar run again, and maybe another thing fell down.

**Interviewer** When you first saw the token, what did you think the image on its screen meant?

**Participant** At first, it was a symbol showing that it was waiting.

**Interviewer** After you flipped it, what did you think it meant? How could you tell when it started and ended?

**Participant** It showed progress. The image changed.

**Interviewer** What did the tower show after the first and second attempts?

**Participant** It showed two blocks stacked like Tetris pieces.

**Interviewer** Do you understand what the blocks mean?

**Participant** One block equals one hour. But I don't understand what it means when they're stacked.

**Interviewer** It means two hours. Yes, each one represents an hour.

**Participant** What happens when they fill the tower?

**Interviewer** We originally planned to design three tokens. When you finish studying, you leave that one alone; then, when you start playing, you flip the play token, and a different shape falls into the tower.

**Participant** So you could see studying, playing, entertainment, and other activities.

**Interviewer** Right. Then you could see how you spent those ten hours of the day.

**Interviewer** If you could change one part of the operation, what would make it clearer and easier?

**Participant** I think the loading bar is a bit hard to understand as a single horizontal line. It would be clearer if an area swept across, or something rotated.

**Interviewer** Imagine the tower was in a shared area at home, like a living room, where you and your roommates could see one another's time. How would you feel?

**Participant** I wouldn't think much of it.

**Interviewer** Would you mind other people seeing how you spend your time?

**Participant** I would mind a little.

**Interviewer** Would you want to see theirs?

**Participant** To be honest, I'm not very interested. I'm not that interested in how long my roommates study or play each day.

**Interviewer** Would seeing other people's schedules make you compare them with your own?

**Participant** Not really. Unless it was a student dorm, especially if everyone was in the same class. If it was a roommate I didn't know, with a different job, studies, and work, there'd be no basis for comparison.

**Interviewer** So you're saying you don't mind seeing theirs, or them seeing yours?

**Participant** I don't want to reveal my own private information. I don't mind seeing theirs because I don't really care about it.

**Interviewer** How would other people's use of time affect you?

**Participant** Only in a dorm environment like those in China: if I saw other people studying for a long time, I might feel a little pressure.

**Interviewer** Would you use this honestly?

**Participant** I don't think I'd have the time. More than whether I'd use it honestly, the issue is that I'd be too lazy to flip it every hour, and I'd have to do it at exactly the right time.

**Interviewer** Would it be different if it were in your own room?

**Participant** Probably not much different. I definitely couldn't record every hour of my day fully, especially if I had to flip it once an hour. For me, that would be almost impossible.

**Interviewer** If you played games for several hours and only operated it once at the start and once at the end, would the display help you?

**Participant** It might remind me I'd been playing for quite a long time. But I wouldn't stop playing just because I saw how long I'd played.

**Interviewer** That's okay. We're not saying you shouldn't play games; we just want you to see the time.
