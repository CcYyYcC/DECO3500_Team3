# Risks

Use this folder to record and manage project risks.

Risk planning should be updated throughout the semester, not only at the end.

## Risk Categories

Risks may include:

- technical risks
- team coordination risks
- scope risks
- user recruitment risks
- data availability risks
- deployment risks
- ethics, privacy, or security risks

## Suggested Risk Format

```markdown
# Risk: [Short Risk Title]

## Description

What could go wrong?

## Likelihood

Low / Medium / High

## Impact

Low / Medium / High

## Mitigation Plan

How will the team reduce the chance or impact of this risk?

## Contingency Plan

What will the team do if the risk occurs?

## Owner

Who is responsible for monitoring this risk?

## Status

Open / Monitoring / Resolved
