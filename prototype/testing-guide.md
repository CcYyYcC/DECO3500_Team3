# Tests and Evaluation

Use this folder for automated tests, technical validation, usability testing materials, and evaluation evidence.

Testing in DECO3801 / DECO7381 is not limited to automated software testing. It may also include usability testing, user evaluation, expert review, technical validation, and prototype demonstrations.

## Default Structure

```text
tests/
├── frontend/
├── backend/
└── integration/
```

---

## Where the evaluation evidence lives

Prototype test transcripts and summaries are kept with the rest of the project evidence, not here:

- [`/research/user_test/Evaluation_01/`](../research/user_test/round_1/) — Round 1: P01–P03 transcripts, EN/ZH combined summaries
- [`/research/user_test/Evaluation_02/`](../research/user_test/round_2/) — Round 2: protocol, P01–P02 transcripts, analysis

This folder is for test materials that belong with the prototype itself (scripts, technical validation, demo instructions).
