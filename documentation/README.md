# Documentation

This folder holds the project's ongoing documentation and evidence: research data, supporting evidence, and design artefacts gathered throughout the semester.

This folder should help teaching staff understand how the team worked, what decisions were made, what risks were managed, and how the project changed over time.

Task and issue tracking is **not** kept here — that lives in the repo's GitHub Projects board (see `.github/ISSUE_TEMPLATE/`). Stand-up records, ethical considerations, and the design process overview are **not** kept here either — those live on the repo's [GitHub Wiki](../README.md#documentation--wiki) (drafts staged in [`/wiki-drafts/`](../wiki-drafts/)).

## Structure

```text
documentation/
├── interviews/           interview transcripts and recordings
├── evidence/              weekly contribution evidence, user testing, screenshots
├── design/                sketches, wireframes, mockups, design rationale
├── decisions/             decision records
├── risks/                 risk register
└── external-resources/    external resources and AI-use disclosure
```
