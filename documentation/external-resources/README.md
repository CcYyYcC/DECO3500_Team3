# External Resources and AI Use Disclosure

Use this folder to document any external resources used in the project.

Examples include:

- open-source code
- libraries
- datasets
- templates
- icons, images, audio, or video
- AI-generated or AI-assisted content
- tutorials or code snippets
- third-party APIs

For each resource, record:

- what was used
- where it came from
- how it was used
- which part of the project it affected
- whether it was modified
