
# Weekly Contribution Evidence

Use this folder to organise weekly evidence of team progress and individual contribution.

This does not replace commits, pull requests, issues, or project board activity. It should help connect the evidence together.

## Suggested Weekly File Name

```md

week-04.md
week-05.md
```
