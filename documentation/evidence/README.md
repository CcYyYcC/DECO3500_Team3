# Evidence

Use this folder for evidence of team progress, individual contribution, user testing, evaluation, and prototype development.

This folder is important because teaching staff may use repository evidence to review project progress and verify student contributions.

Avoid vague statements such as "We worked on the backend."

Prefer specific evidence such as: "Implemented login API endpoint. Evidence: pull request #12, commits abc123 and def456, tested using integration test login-api.test.js."

Students may be asked to explain and demonstrate their own contribution. Do not claim work that you cannot explain, justify, or demonstrate.
